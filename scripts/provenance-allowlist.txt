# Files listed here are permitted to contain patterns that
# scripts/check-provenance.sh would otherwise reject.
#
# Format:  <path-glob>|<extended-regex>
#
#   * One entry per line.
#   * The regex is matched against the file's contents with grep -E.
#   * Blank lines and lines starting with '#' are ignored.
#
# Keep this list as short as possible. Every entry is a deliberate decision,
# and each should have a comment explaining why it is needed.
#
# ---------------------------------------------------------------------------
